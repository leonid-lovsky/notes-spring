# 44 · Google Docs Export

Level: middle. Status: not started.

## Change

A user exports a note to Google Docs.

## Why

In 43 a note cannot leave the application.

## Tools

OAuth2 Client with Google and the Google Docs API; the acceptance tests do not cover it.

## Proof

- The acceptance tests pass.
- An exported note appears in Google Docs with its formatting.
