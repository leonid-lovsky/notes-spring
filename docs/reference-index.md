# Путеводитель по документации `notes-spring` (снимок 2026-09-26)

Точка входа в справочные материалы: для каждого файла `docs/` — назначение, когда читать, ключевые разделы; ниже — «вопрос → где ответ». Точка входа в проект — по-прежнему `CLAUDE.md` (правила, задачи, открытые решения); этот файл его не заменяет, а ведёт по `docs/`. При создании/удалении/переименовании файла в `docs/` — обновлять и этот путеводитель (вместе с `docs/file-catalog.md`, CLAUDE.md → «Правила» → «Актуальность `docs/file-catalog.md`»).

## Файлы — назначение, когда читать, ключевые разделы

### Архитектура и обсуждения (консультации, не решения)

- `docs/microservices-reference.md` — снимок итогов сессии 2026-09-26 по микросервисной архитектуре — читать первым при возврате к микросервисам, сервисам, Spring Cloud, security/валидации/ошибкам, границам — разделы: «Предпочтения пользователя…», «⚠️ Основной вопрос микросервисной архитектуры», «Сервисы и ответственность», «Классический набор Spring Cloud…», «Компоненты Spring Cloud — подробности», «Модель `UserNote` без прав», «Где реализуется Security», «…валидация», «…обработка ошибок», «…технологии», «Выбор технологии при запуске», «Границы модулей и сервисов», «Открыто (решает пользователь)»
- `docs/user-note-access-model.md` — полный ход обсуждения модели доступа `UserNote` 2026-09-25→2026-09-26 (история рассуждения, код-эскизы, отклонённые варианты, аналоги) — читать при возврате к правам/ролям/хранению прав или когда нужен «почему», а не «что» — разделы: «Ключевые выводы обсуждения 2026-09-25», «Точка остановки», «Итоговая модель целиком — код по модулям», «Направление 2026-09-26…», «Продолжение 2026-09-26…» (списки с правами (А)/(Б)/(В), именование по HTTP, эскизы интерфейсов/контроллеров, сервисы и стартеры), «Нерешённое на 2026-09-25», «Рассмотренные и отклонённые варианты», «Аналоги из индустрии», «Инварианты по слоям — UI / Framework / Model / Storage»
- `docs/decisions-log.md` — хронология принятых архитектурных решений и переписывания `user-note/` 2026-08-14→2026-09-25 — читать при пересмотре конкретного решения (grep по дате/теме) — разделы: «Архитектура», «HTTP / Ошибки», «Маппинг», «Reactive-семантика», «Convention plugins…», «Синхронизация версий», «Стиль кода», «Хронология переписывания `user-note/`…»
- `docs/google-docs-full-model.md` — набросок требований к совместному редактированию документов — читать только при возврате к этой теме (не реализовывать до запроса)

### Структура проекта (снимки текущего состояния)

- `docs/tree-variants.md` — «дерево вариантов» (8 листьев: sync/reactive × технология × вендор) — читать перед любым архитектурным решением (CLAUDE.md → «Правила» → «Любое архитектурное решение проверять на корневом дереве вариантов»); источник истины — CLAUDE.md → «Корневое дерево вариантов»
- `docs/tree-modules.md` — «дерево модулей»: все листья `user-note/` с пакетом и напрямую применёнными convention-плагинами — читать при правке `build.gradle.kts` модулей
- `docs/tree-project.md` — «дерево проекта»: ASCII-снимок каталогов — читать для ориентации в раскладке
- `docs/tree-repositories.md` — «дерево репозиториев» Spring Data — краткая форма `docs/spring-data-repository-reference.md`
- `docs/convention-plugins-graph.md` — граф родитель→потомок всех convention-плагинов по уровням — читать при правке/добавлении плагина в `build-logic/` (вместо реконструкции по хронологии) — раздел «Как читать этот граф»
- `docs/file-catalog.md` — каталог всех файлов со статусами `[DONE]`/`[REVIEW]`/`[ADD]`/`[REMOVED]` — синхронизировать при каждом создании/удалении/переименовании файла; ⛔ статусы не менять по инициативе агента (CLAUDE.md → «Правила» → «Лимит размера файла»)

### Справочники по технологиям

- `docs/spring-boot-starters-reference.md` — дословная копия Spring Initializr (стартеры, BOM, `-test`-пары) — источник истины для «существует ли стартер X» и «как называется» (grep по точной строке, не Maven Central); ⛔ список не сокращать
- `docs/spring-boot-starters-full-matrix.md` — сырой снимок всех 205 зависимостей Initializr по Boot 4.0.7/4.1.0 × Java 21/25 — кругозор, не источник для convention-плагинов
- `docs/spring-boot-testing-reference.md` — тестовые аннотации и классы Spring Boot 4.1 с датами появления — читать при выборе тестовой аннотации/клиента (слайсы, `@SpringBootTest`, мокирование, Testcontainers)
- `docs/spring-data-repository-reference.md` — иерархия репозиториев Spring Data по вендорам проекта (JDBC/R2DBC/Mongo sync+reactive) — читать при выборе базового интерфейса репозитория — разделы: «Почему у JDBC нет своего интерфейса…», «Что реально использует проект»
- `docs/db-migration-tools-reference.md` — инструменты миграции БД по каждому driven-адаптеру (Flyway/Liquibase, Mongock/Flamingock) — выбор не сделан
- `docs/tech-glossary.md` — глоссарий технологий вне Spring-стека (Kubernetes, Terraform, Kafka, OAuth2, Axon и др.) — читать при работе с конкретной технологией из списка

### Работа ассистента

- `docs/agent-working-agreements.md` — договорённости о работе ассистента и предпочтения пользователя, зеркало памяти агента — разделы: «Общение», «Роль и инициатива», «Как рассуждать», «Факты и источники», «Работа с проектом», «Предпочтения пользователя к коду и инструментам»

## Вопрос → где ответ

- что сейчас в работе, точка возврата — CLAUDE.md → «Задачи» → «Точка возврата»
- центральный вопрос (одинаковое поведение на вендорах) — CLAUDE.md → «Открытые решения» → первый пункт
- основной вопрос микросервисной архитектуры (списки с правами) — `docs/microservices-reference.md` → «⚠️ Основной вопрос…»; варианты хранения — `docs/user-note-access-model.md` → «Списки с перечнем прав доступа — три варианта хранения»
- какие сервисы нужны и кто за что отвечает — `docs/microservices-reference.md` → «Сервисы и ответственность», «Классический набор Spring Cloud…»
- Gateway / Eureka / OpenFeign / Resilience4j / Config Server — `docs/microservices-reference.md` → «Компоненты Spring Cloud — подробности»
- где security / валидация / ошибки / Redis-Kafka-OpenFeign — `docs/microservices-reference.md` → одноимённые разделы «Где реализуется…»
- выбрать технологию при запуске или при сборке — `docs/microservices-reference.md` → «Выбор технологии при запуске»
- границы модулей и сервисов, split package — `docs/microservices-reference.md` → «Границы модулей и сервисов»
- модель `UserNote` без прав, use case, контроллер — `docs/microservices-reference.md` → «Модель `UserNote` без прав»; эскизы — `docs/user-note-access-model.md` → «Продолжение 2026-09-26…»
- права, роли, инварианты, «все лишились доступа» — `docs/user-note-access-model.md` → «Точка остановки», «Нерешённое на 2026-09-25»
- существует ли стартер, `-test`-пара — `docs/spring-boot-starters-reference.md` (grep)
- какой convention-плагин есть / куда добавить новый — `docs/convention-plugins-graph.md`
- какая тестовая аннотация — `docs/spring-boot-testing-reference.md`
- какой репозиторий Spring Data — `docs/spring-data-repository-reference.md`
- почему принято решение X — `docs/decisions-log.md` (grep по дате/теме)
- как вести себя ассистенту — `docs/agent-working-agreements.md`, CLAUDE.md → «Правила»
